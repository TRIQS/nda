nda::F_layout_str
Memory layout » Layout policies

#include <nda/layout/rect_str.hpp>

Detailed Description

Contiguous layout policy with Fortran-order (column-major order) and possible string indices.

The first dimension varies the fastest, the last dimension varies the slowest.
