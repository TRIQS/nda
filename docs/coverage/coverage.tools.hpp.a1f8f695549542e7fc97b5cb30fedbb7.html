135 /**
136 * @brief A type-erased, non-owning view of an nda::MemoryArray or a conjugate lazy expression.
137 *
138 * @details It holds a pointer to the data, extents and strides of the viewed array or conjugate expression, as well
139 * as its rank and an element-wise unary operation to apply to each element (see nda::tensor::unary_op).
140 *
141 * All pointers are non-owning and must remain valid for the lifetime of this object.

143 * @tparam T Value type of the tensor.
144 */

168 /**
169 * @brief Construct a rank-0 tensor view from a pointer to a scalar value.

171 * @details This creates a tensor view with `ndim == 0` and `extents == strides == nullptr`, viewing the scalar as a

176 tensor_view(T *p) : data(p) {}
