29 /**
30 * @brief In-place elementwise binary tensor operation with cuTENSOR/nda dispatch.
31 *
32 * @details This function performs an in-place elementwise binary operation of the form
33 * \f[
34 * B_{\text{idx}_B} \leftarrow \text{op}\bigl(\alpha \, A_{\text{idx}_A}, \, \beta \, B_{\text{idx}_B}\bigr) \;,
35 * \f]
36 * where \f$ \alpha \f$ and \f$ \beta \f$ are scalars, \f$ A \f$ and \f$ B \f$ are tensors, and \f$ \text{op} \f$ is a
37 * binary operation (see nda::tensor::binary_op). The index strings specify how the dimensions of \f$ A \f$ map to
38 * those of \f$ B \f$ (Einstein notation); when ranks differ on the cuTENSOR path, indices present in one tensor but
39 * absent from the other drive broadcast/reduction on the backend.
40 *
41 * <details>
42 * <summary>**Dispatch order and details**:</summary>
43 * - If the input arrays satisfy nda::mem::have_device_compatible_addr_space, cuTENSOR's elementwise binary operation
44 * is used.
45 * - Otherwise, fallback to nda expression assignment via nda::map.
46 *
47 * The supported binary operations depend on the library backend. The nda host fallback requires identical ranks
48 * and identical index strings and supports all nda::tensor::binary_op values.
49 * </details>
50 *
51 * @note \f$ A \f$ is allowed to be a lazy conjugate expression (see nda::blas_lapack::is_conj_array_expr).
52 *
53 * @tparam A nda::blas_lapack::BlasArrayOrConj type.
54 * @tparam B nda::blas_lapack::BlasArrayFor<A> type.
55 * @param alpha Input scalar \f$ \alpha \f$.
56 * @param a Input tensor \f$ A \f$.
57 * @param idx_a Index string \f$ \text{idx}_A \f$ for tensor \f$ A \f$.
58 * @param beta Input scalar \f$ \beta \f$.
59 * @param b Input/Output tensor \f$ B \f$.
60 * @param idx_b Index string \f$ \text{idx}_B \f$ for tensor \f$ B \f$.
61 * @param op Binary operation (default: `binary_op::SUM`).
