28 /**
29 * @brief Controls evaluation behavior of function nodes during partial expression evaluation.
30 *
31 * When partially evaluating an expression tree, function nodes have two evaluation modes:
32 * - false (default): Function is evaluated only if all arguments are non-lazy values.
33 * If any argument is lazy, the node is preserved with evaluated children but the
34 * function itself is NOT called.
35 * - true: Function is ALWAYS called with all arguments (lazy or non-lazy).
