115 /**
116 * @brief Given an nda::idx_map and a partition of its indices, return a new nda::idx_map with the grouped indices.
117 *
118 * @details It is used to create an nda::group_indices_view: `group_indices_view(A, idx_group<i,j,...>,
119 * idx_group<k,l,...>, ...)`. The resulting index map is of rank `sizeof...(IdxGrps)` with merged indices, one for
120 * each group.
121 *
122 * Preconditions:
123 * - The given index groups correspond to a partition of the set `{0, 1, ..., R - 1}` where `R` is the rank.
124 * - In each group the indices are consecutive in memory.
125 *
126 * For example, let's look at the following strider order: `S = (2, 1, 0)`. That means that dimension 0 is the fastest
127 * varying index, then dimension 1 and dimension 2 is slowest. We say that dimensions 0 and 1 are consecutive in
128 * memory. The same goes for dimensions 2 and 1. However, dimensions 0 and 2 are not consecutive in memory.
129 *
130 * To check if a group of indices are consecutive in memory, we look at the inverse permutation of the stride order.
131 * The stride order `S` is a permutation which maps an integer j to a dimension/index i of the array such that
132 * `S[j] = i` is the (j+1)-th slowest varying index, i.e. `S[0]` is the slowest index and `S[R - 1]` is the fastest.
133 * The inverse permutation, `M = S^{-1}`, therefore tells us how fast a given index varies, e.g. `M[i] = j` means that
134 * index i varies the (j+1)-th slowest.
135 *
136 * @tparam Rank Rank of the original nda::idx_map.
137 * @tparam StaticExtents Static extents of the original nda::idx_map.
138 * @tparam StrideOrder Stride order of the original nda::idx_map.
139 * @tparam LayoutProp Layout property of the original nda::idx_map.
140 * @tparam IdxGrps Groups of indices.
141 *
142 * @param idxm Original nda::idx_map.
143 * @return New nda::idx_map with the grouped indices.
144 */
