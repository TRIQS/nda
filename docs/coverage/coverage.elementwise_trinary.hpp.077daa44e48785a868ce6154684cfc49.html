29 /**
30 * @brief In-place elementwise trinary tensor operation with cuTENSOR/nda dispatch.
31 *
32 * @details This function performs an in-place elementwise trinary operation of the form
33 * \f[
34 * C_{\text{idx}_C} \leftarrow \text{op}_{ABC} \bigl( \text{op}_{AB} \bigl( \alpha \, A_{\text{idx}_A}, \, \beta \,
35 * B_{\text{idx}_B} \bigr), \, \gamma \, C_{\text{idx}_C} \bigr) \;,
36 * \f]
37 * where \f$ \alpha \f$, \f$ \beta \f$ and \f$ \gamma \f$ are scalars, \f$ A \f$, \f$ B \f$ and \f$ C \f$ are tensors
38 * of arbitrary (possibly different) ranks, and \f$ \text{op}_{ABC} \f$ and \f$ \text{op}_{AB} \f$ are binary
39 * operations (see nda::tensor::binary_op). The index strings determine the einsum-style mapping between operands;
40 * indices absent from one operand drive broadcast/reduction on the backend.
41 *
42 * <details>
43 * <summary>**Dispatch order and details**:</summary>
44 * - If the input arrays satisfy nda::mem::have_device_compatible_addr_space, cuTENSOR's elementwise trinary operation
45 * is used.
46 * - Otherwise, fallback to nda expression assignment via nda::map.
47 *
48 * The supported binary operations depend on the library backend. The nda host fallback requires identical ranks
49 * and identical index strings and supports all nda::tensor::binary_op values for both `op_AB` and `op_ABC`.
50 * </details>
51 *
52 * @note \f$ A \f$ and \f$ B \f$ are allowed to be lazy conjugate expressions (see
53 * nda::blas_lapack::is_conj_array_expr).
54 *
55 * @tparam A nda::blas_lapack::BlasArrayOrConj type.
56 * @tparam B nda::blas_lapack::BlasArrayOrConjFor<A> type.
57 * @tparam C nda::blas_lapack::BlasArrayFor<A> type.
58 * @param alpha Input scalar \f$ \alpha \f$.
59 * @param a Input tensor \f$ A \f$.
