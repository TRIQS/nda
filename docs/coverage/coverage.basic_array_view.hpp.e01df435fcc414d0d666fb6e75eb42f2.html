59 /**
60 * @ingroup arrays_views
61 * @brief A generic view of a multi-dimensional array.
62 *
63 * @details Together with nda::basic_array, this class forms the backbone of the nda library. It is templated with
64 * the following parameters:
65 *
66 * - `ValueType`: This is the type of the elements in the view. Depending on how the view was constructed and on the
67 * underlying array, this can be a const or non-const type.
68 * - `Rank`: Integer specifying the number of dimensions of the view. This is a compile-time constant.
69 * - `LayoutPolicy`: The layout policy specifies how the view accesses its elements. It provides a mapping from
70 * multi-dimensional to linear indices and vice versa (see @ref layout_pols).
71 * - `Algebra`: The algebra specifies how the view behaves when it is used in an expression. Possible values are 'A'
72 * (array), 'M' (matrix) and 'V' (vector) (see nda::get_algebra).
73 * - `AccessorPolicy`: The accessor policy specifies how the view accesses the data pointer. This can be useful for
74 * optimizations.
75 * - `OwningPolicy`: The owning policy specifies the ownership of the data pointer and who is responsible for
76 * handling the memory resources (see @ref mem_handles).
77 *
78 * In contrast to regular arrays (see nda::basic_array), views do not own the data they point to. They are a fast and
79 * efficient way to access and manipulate already existing data:
80 *
81 * @code{.cpp}
82 * // create a regular 3x3 array of ones
83 * auto arr = nda::ones<int>(3, 3);
84 * std::cout << arr << std::endl;
85 *
86 * // zero out the first column
87 * arr(nda::range::all, 0) = 0;
88 * std::cout << arr << std::endl;
89 * @endcode
90 *
91 * Output:
92 *
93 * @code{bash}
94 *
95 * [[1,1,1]
96 * [1,1,1]
97 * [1,1,1]]
98 *
99 * [[0,1,1]
100 * [0,1,1]
101 * [0,1,1]]
102 * @endcode
103 *
104 * Views are usually created by taking a slice of a regular nda::basic_array or another view. In the example above,
105 * `arr(nda::range::all, 0)` creates a view of the first column of the regular array `arr`, which is then set to zero.
106 * A view of the full array can be created with `arr()`.

108 * @tparam ValueType Type stored in the array.
109 * @tparam Rank Number of dimensions of the view.
110 * @tparam LayoutPolicy Policy determining the memory layout.
