199 /**
200 * @brief Compile-time guarantees of the memory layout of an array/view.
201 *
202 * @details The possible values are:
203 * - `none`: No guarantees.
204 * - `strided_1d`: There is a constant overall stride in memory.
205 * - `smallest_stride_is_one`: The stride in the fastest dimension is 1.
206 * - `contiguous`: The array/view is contiguous in memory, i.e. it is `strided_1d` and `smallest_stride_is_one`.
207 *
208 * Furthermore, the set of values has a partial order:
209 * - `contiguous` > `strided_1d` > `none`
