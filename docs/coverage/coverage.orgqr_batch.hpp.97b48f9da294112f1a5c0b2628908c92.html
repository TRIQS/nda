26 * @details This function generates the orthogonal matrix \f$ \mathbf{Q}_i \f$ for each matrix in a batch indexed by
27 * \f$ i \in \{ 0, \ldots, N_b - 1 \} \f$ from the elementary reflectors and scalar factors produced by
28 * nda::lapack::geqrf_batch. Here, \f$ N_b \f$ is the batch size. See also nda::lapack::orgqr.
29 *
30 * A batch of matrices is just a 3-dimensional array in nda::F_layout where the last dimension indexes the individual
31 * matrices such that `A(:,:,i)` corresponds to the \f$ i \f$-th matrix \f$ \mathbf{A}_i \f$ in the batch.
32 *
33 * No library-level batching is currently available for this function. Instead, the function simply loops over all
34 * matrices in the batch and calls nda::lapack::orgqr on the first \f$ \min(m, n) \f$ columns of each slice. For wide
35 * matrices (\f$ m < n \f$), this produces an \f$ m \times m \f$ orthogonal matrix in the first \f$ m \f$ columns of
36 * each slice; the remaining columns are left untouched.
37 *
38 * @note \f$ \mathbf{A} \f$ and \f$ \mathbf{T} \f$ are required to have nda::F_layout.
39 *
40 * @tparam A nda::blas_lapack::BlasArrayReal<3> type.

42 * @tparam W nda::blas_lapack::BlasArrayFor<A, 1> type.
43 * @param a Input/output array. On entry, the 3-dimensional array containing the elementary reflectors for each batch
44 * (as returned by nda::lapack::geqrf_batch). On exit, the first \f$ \min(m, n) \f$ columns of each slice contain

71 /**
72 * @ingroup linalg_lapack
73 * @brief Generic-friendly overload of nda::lapack::orgqr for batches stored as 3-dimensional arrays.
74 *
75 * @details It simply calls nda::lapack::orgqr_batch and lets generic code call `%orgqr(...)` regardless of whether
76 * the input is a single matrix (rank 2) or a batch (rank 3).
77 */
78 template <BlasArrayReal<3> A, BlasArrayFor<A, 2> TAU, BlasArrayFor<A, 1> W = vector_value_t<A>>
79 requires(has_F_layout<A, TAU>)
80 int orgqr(A &&a, TAU &&tau, W &&work = vector_value_t<A>{}) { // NOLINT (temporary views are allowed here)
81 return orgqr_batch(std::forward<A>(a), std::forward<TAU>(tau), std::forward<W>(work));
