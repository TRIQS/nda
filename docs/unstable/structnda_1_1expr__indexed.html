Detailed Description

template<typename View, typename... IndexContainers>
struct nda::expr_indexed< View, IndexContainers >

Lazy expression for advanced array indexing with arbitrary index containers.

This expression type enables NumPy-style advanced indexing where arrays can be indexed with containers of arbitrary integers (e.g., std::vector<long>). Unlike regular slicing which returns a view, advanced indexing returns a lazy expression because the selected elements may not be contiguous in memory.

The expression stores:

  • A view of the source array (with any range-based slicing already applied)
  • Index containers converted to std::vector<long>
  • Information about which dimensions use index containers

Example usage:

nda::array<double, 2> arr(10, 20);
std::vector<long> indices = {3, 7, 1};
auto expr = arr(indices, nda::range::all); // Returns expr_indexed
nda::array<double, 2> result = expr; // Materializes the expression
